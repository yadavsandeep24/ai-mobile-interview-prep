# AI in Mobile Dev — 30-Minute Daily Interview Prep

A 30-day, Android-first (with iOS comparisons) curriculum for interviews on building AI features into mobile apps.

## Daily format (30 min)

| Block | Time |
|---|---|
| Concept | 10 min |
| Code | 10 min |
| Mini system design | 5 min |
| Mock interview questions (answer out loud) | 5 min |
